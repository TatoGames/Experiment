# inch — 간편한 단위 변환기

숫자를 입력하면 즉시 결과를 보여주는 한국어 단위 변환기입니다. HTML, CSS, JavaScript를 `index.html` 하나에 담았으며, 빌드 도구·외부 라이브러리·이미지·네트워크 연결 없이 실행됩니다.

## 실행 방법

1. 저장소의 `inch` 브랜치에서 `index.html`을 다운로드합니다.
2. 파일을 더블클릭해 Chrome, Edge, Firefox, Safari 같은 최신 브라우저로 엽니다.
3. JavaScript가 활성화되어 있으면 바로 사용할 수 있습니다. 서버 설치나 별도 빌드는 필요하지 않습니다.

## 사용 방법

1. **길이**, **무게**, **온도** 중 원하는 카드의 **변환할 값**에 숫자를 입력합니다.
2. 숫자 오른쪽에서 입력 단위를, **변환 결과** 오른쪽에서 결과 단위를 선택합니다.
3. 입력하거나 단위를 바꾸는 즉시 결과가 갱신됩니다. 각 카드는 독립적으로 동작합니다.
4. **⇅** 버튼을 누르면 입력 단위와 결과 단위가 맞바뀝니다. 입력한 숫자는 유지됩니다.
5. 카드 아래 **이렇게 써보세요**를 누르면 예시 값과 단위가 적용됩니다.
6. **전체 초기화**를 누르면 세 카드가 처음의 값과 단위로 돌아갑니다.

소수·음수·0을 입력할 수 있으며, 입력을 지우면 결과가 `—`로 표시됩니다. 같은 단위끼리는 입력값이 그대로 표시됩니다. 키보드의 Tab 키로 입력창·단위 선택·버튼을 이동할 수 있습니다. 모바일에서도 사용할 수 있습니다.

## 지원 단위와 변환 기준

| 종류 | 지원 단위 | 기준 |
| --- | --- | --- |
| 길이 | m, cm, inch | 1 m = 100 cm, 1 inch = 2.54 cm |
| 무게 | kg, lb | 1 lb = 0.45359237 kg (국제 파운드) |
| 온도 | °C, °F | °F = °C × 9 / 5 + 32, °C = (°F − 32) × 5 / 9 |

각 종류에서 양방향 변환을 지원합니다. 결과는 유효숫자 최대 12자리로 표시하며, 절댓값이 10¹² 이상이거나 0보다 크고 10⁻⁶ 미만이면 지수 표기를 사용합니다. 내부 계산은 JavaScript의 부동소수점을 사용하므로 미세한 오차가 있을 수 있습니다. 표시 범위를 넘는 결과에는 안내 문구가 나옵니다.

## 확인 예시

| 입력 | 결과 단위 | 예상 결과 |
| --- | --- | --- |
| 1 m | cm | 100 |
| 1 inch | cm | 2.54 |
| 100 cm | m | 1 |
| 1 lb | kg | 0.45359237 |
| 1 kg | lb | 약 2.20462262185 |
| 0 °C | °F | 32 |
| 212 °F | °C | 100 |
| −40 °C | °F | −40 |
